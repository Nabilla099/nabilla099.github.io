## Struktur Repository

- `index.html` / `index.md` — Halaman utama situs.
- `assets/` — Gambar, stylesheet, dan berkas statis.
- `_config.yml` — (opsional) konfigurasi Jekyll bila digunakan.
- `README.md` — Dokumentasi singkat (file ini).

---

## Cara Mengedit & Mempublikasikan

1. Fork atau clone repository ini.
2. Buat cabang baru untuk perubahan (mis. `feature/update-bio`).
3. Edit file HTML/CSS/Markdown.
4. Commit dan push perubahan ke GitHub.
5. Merge ke cabang default (`main`) untuk memicu GitHub Pages.

Perubahan akan diterbitkan otomatis oleh GitHub Pages dalam beberapa menit.

## Personalisasi Tampilan (Tip)

- Gunakan folder `assets/images/` untuk foto profil dan aset.
- Ubah warna dan font di file CSS untuk mendapatkan tampilan "cute" (pink lembut & putih bersih).
