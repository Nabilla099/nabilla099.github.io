  <h1>Kh-Store itu apa?</h1>
  <p class="lead">
    Kh-Store adalah etalase koleksi game Java J2ME untuk HP jadul — tempat kumpul buat kamu yang kangen
    main game di layar kecil kayak dulu. Setiap game punya halaman sendiri, lengkap dengan screenshot,
    deskripsi, dan spesifikasi, biar kamu tahu persis apa yang bakal kamu mainkan sebelum download.
  </p>
  <p class="lead">
    Semua file game diambil dari <strong>link pihak ketiga</strong> — Kh-Store tidak menghosting file
    game itu sendiri, cuma menampilkan katalog dan informasinya.
  </p>
  <p class="lead">
    Punya game favorit yang belum ada di sini? Kirim rekomendasinya lewat menu <strong>Request Game</strong>
    di halaman utama.
  </p>
